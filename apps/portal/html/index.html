Why
Built to be
trusted with
real work.

A laptop is a bad place to run Postgres, Kafka and a monitoring stack — it sleeps, runs out of RAM, and nothing survives a reboot. This box moves all of that to an always-on machine with 10 cores and 23 GB, reachable anywhere over Tailscale, so the laptop stays light and the infrastructure stays put.

It isn't just "some containers." It's an environment that watches its own health, emails you when something breaks, and can't quietly lose your data — memory-capped, auto-restarting, backed up nightly, version-controlled in ~/stacks, and documented in the wiki.

Roadmap
What's next
  • Single-domain reverse proxy + local TLS — services at name.dev instead of ports.
  • Two-way Git sync for the wiki — every page versioned as Markdown on disk.
  • A project workspace on devnet with hot-reload against the shared databases.
  • More dashboards & alert rules — per-service SLOs and restart-storm detection.
  • Secrets hardening — rotate the dev credentials into a managed store.
  • CI → deploy to minikube via tilt for a real inner-loop.
