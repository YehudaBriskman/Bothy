Why this box exists

A laptop is a bad place to run Postgres, Kafka and a monitoring stack — it sleeps, it runs out of RAM, and nothing survives a reboot. This box moves all of that to a always-on machine with 10 cores and 23 GB, reachable from anywhere over Tailscale, so the laptop stays light and the infrastructure stays put.

The goal isn't just "run some containers" — it's an environment you can trust with real work: it watches its own health (Grafana + Prometheus), tells you when something breaks (email alerts), and can't lose your data (nightly backups, memory limits, auto-restart). Everything is version-controlled in ~/stacks and documented in the wiki.

Roadmap

  • Single-domain reverse proxy + local TLS, so services live at name.dev instead of ports
  • Two-way Git sync for the wiki — every page versioned as Markdown
  • A project workspace on devnet with hot-reload against the shared DBs
  • More Grafana dashboards & alert rules (per-service SLOs, restart storms)
  • Secrets hardening — rotate the dev credentials into a managed secret store
  • CI → deploy to minikube via tilt for a real inner-loop
